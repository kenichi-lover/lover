# 功能
1. 博客列表
   路由 + 视图（时间倒序排序） + 序列化
2. 博客详细
   路由（PK）+ 新视图或原视图 + 序列化
3. 评论列表
   在URL上通过GET方式传入博客ID，根据博客ID获取相关评论
   提示：请求可以单独，也可以在博客详细的请求中返回。
4. 注册
   输入用户信息+重复密码进行注册
5. 登录
   登录成功，生成TOKEN+失效日期，返回。
6. 创建评论（需登录）
   在URL上通过GET方式传入博客ID + 请求体中评论信息，发送到后端API
   -- 认证组件，REQUEST.USER
   -- 构造参数保存
7. 点赞（需登录）
   -- 赞过不能再赞
   -- 结合事务实现添加赞 + 赞数量更新
8. 新建博文（需登录）
